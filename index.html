Si agregás más de uno, los clientes van a poder elegir quién los atiende y cada uno tendrá su propia agenda.
Para que los recordatorios se envíen solos todos los días, hace falta activar el disparador una vez desde el editor de Apps Script (función instalarRecordatorios). Ver instrucciones al inicio de Code.gs.
Los clientes podrán reservar por WhatsApp. Con la API de Meta configurada en Apps Script, el bot responde automáticamente.
Bot automático de WhatsApp Business (opcional)
1. Creá una app en Meta for Developers → WhatsApp → API Setup.
2. En Apps Script → ⚙ Project Settings → Script properties, agregá:
  WHATSAPP_TOKEN, WHATSAPP_PHONE_ID, WHATSAPP_VERIFY_TOKEN
3. Volvé a Implementar → Nueva versión de la Web App.
4. En Meta → WhatsApp → Configuration → Webhook, pegá la URL /exec y el mismo verify token; suscribite a messages.
El bot permite agendar, ver horarios y consultar turnos por WhatsApp. Además envía confirmación al reservar desde la web.
